# 📖 Livrinho Infantil Digital

Uma aplicação interativa com histórias ilustradas para crianças.

## ✨ Funcionalidades

- **📚 Múltiplas histórias** - Escolha entre várias histórias ilustradas
- **🗣️ Narração automática** - SpeechSynthesis API para ouvir as histórias
- **🎵 Música de fundo** - Trilha sonora suave para cada história
- **🌙 Modo noite** - Tema escuro para hora de dormir
- **❤️ Favoritos** - Marque suas histórias preferidas
- **🎯 Categorias** - Filtre por amizade, aventura ou animais
- **⚡ Velocidade ajustável** - Controle a velocidade da narração
- **📱 Responsivo** - Funciona em tablet e celular
- **⌨️ Atalhos** - Navegue com setas do teclado e espaço

## 🚀 Como Usar

1. Abra `index.html` no navegador
2. Escolha uma história clicando no card
3. Use os botões ou setas do teclado para navegar
4. Ative a narração com o botão 🗣️
5. Ative a música com o botão 🎵
6. Use 🌙 para modo noite

## 🎮 Atalhos do Teclado

- `←` / `→` - Página anterior/próxima
- `Espaço` - Ativar/desativar narração
- `Esc` - Voltar ao menu
